# Predictive Call Center Optimization & KPI Impact Analysis

## Overview
This project applies predictive modeling and operational analytics to identify high-risk call scenarios and quantify their impact on key call center KPIs such as Average Speed to Answer (AST) and Average Handle Time (AHT).

## Problem Statement
Call centers often face extreme wait times driven by a small subset of high-risk calls. This project aims to:
- Identify patterns contributing to elevated AHT and AST
- Predict high-risk calls using machine learning models
- Simulate operational interventions to reduce wait times

## Methodology
- Performed exploratory analysis on operational, behavioral and sentiment-related features
- Engineered features relevant to call complexity and queue behavior
- Trained Logistic Regression and Random Forest models to classify high-risk calls
- Evaluated model performance and analyzed feature importance
- Simulated ML-driven call prioritization strategies to estimate KPI improvements

## Key Results
- Achieved **86% model accuracy** in predicting high-risk call scenarios
- Identified key operational drivers contributing to extreme wait times
- Simulated a **12% reduction in AST** and **76% fewer extreme wait cases** through ML-based prioritization
